# Vidéo — Créer sa boutique sur UzaApp

Kit de production pour une vidéo courte (~75 s) réseaux sociaux.

## Fichiers

| Fichier | Description |
|---------|-------------|
| `script_voix_off.txt` | Script brut pour téléprompteur |
| `script_voix_off.md` | Script avec repères temps et conseils d'enregistrement |
| `script_voix_off.srt` | Sous-titres pour le montage |
| `voix_off_reference.wav` | Piste voix de référence (SAPI Windows) — à remplacer par votre voix |
| `shot_list.md` | Plan de capture d'écran |
| `montage_timeline.md` | Timeline voix / image synchronisée |
| `raw/` | Déposer les enregistrements bruts ici |
| `export/` | Exporter la vidéo finale ici |

## Workflow

1. **Voix** — Enregistrer avec `script_voix_off.md` (remplacer `voix_off_reference.wav`)
2. **Captures** — Suivre `shot_list.md` sur un téléphone avec UzaApp
3. **Montage** — Suivre `montage_timeline.md`, importer `script_voix_off.srt`
4. **Export** — `export/creer_sa_boutique_final_9x16.mp4`
